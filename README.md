## 👋 Hi, I'm Eden

I'm a third-year Industrial Engineering and Management student at Ben-Gurion University. What draws me in is the point where a business problem meets a technical solution: understanding how a process really works, modeling it, and building something that supports it. I've done this end to end in two course projects, a studio management system and an e-commerce database.

Before university I served as an Air Traffic Controller in the Israeli Air Force, where I managed real-time operations, led a shift team and made decisions under pressure.

**Looking for:** student positions in product, project management, and data and business analysis. Israel.

## 🚀 Featured projects

### 🏋️ [LEVEL UP Studio Management System](https://github.com/edenkompel/level-up-management)

A management system for a fitness studio in Be'er Sheva that ran on WhatsApp reminders, a whiteboard and a parallel Excel sheet. I took part in the full cycle: stakeholder interviews, process mapping, requirements, UML design, and implementation of a C# .NET desktop application on SQL Server, with Google Calendar and Tasks integration and email notifications. Built with AI-assisted development (Claude Code).

**Tools:** C# · .NET 8 · WinForms · SQL Server · BPMN · UML

### 💎 [Zales Jewelry E-Commerce Database](https://github.com/edenkompel/zales-database)

A relational database for a jewelry e-commerce site, including personalized jewelry orders. It goes from business analysis and ERD modeling to SQL Server, analytical queries (CTEs, window functions), views, a trigger, a stored procedure, and a Power BI sales dashboard.

**Tools:** SQL Server · T-SQL · Power BI · ERD
